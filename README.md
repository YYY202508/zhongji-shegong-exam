# 中级社工备考

面向 2027 年中级社会工作师（社会工作师资格）的备考技能。默认练中级三科：综合能力、实务、法规与政策。2026 年及以前的卷子当作历年真题。初级题目也在题库里，只有明确要练初级时才抽。

技能自己带题库、速记卡片和判分脚本。学习、复习、刷题都不读 PDF。原始 PDF 仍在 `D:\工作\社工证资料`，只有要看某一页原件时才去那里找。

教练用中文，一次只做一件事：有到期章节就复习，否则学下一章。一次只讲一节，一次只出一题。作答之前不出答案和解析。

## 考试和技能怎么对应

大纲按 2025 年版。2026 年 5 月已经按这版考过，2027 年仍用这版做骨架。第一次使用会问教材是中社版还是人大版，不指定就按中社版。

| 科目 | 时长 | 卷面 | 技能里的模拟考 |
| --- | --- | --- | --- |
| 综合能力 | 2 小时 | 100 分，60 分及格 | 单选 60 题，每题 1 分；多选 20 题，每题 2 分 |
| 法规与政策 | 2 小时 | 100 分，60 分及格 | 同上 |
| 实务 | 2.5 小时 | 100 分，60 分及格 | 案例分析 4 题 + 方案设计 1 题，每题 20 分 |

多选从 5 个选项里选。错选、多选是 0 分；少选时，选对的每一项 0.5 分。成绩两年滚动，连续两个考试年度内三科都过才发证。

## 每天怎么安排

说「今天做什么」或刚开始用，运行：

```bash
python scripts/learn.py today
```

说「开始」或「继续今天的」：

```bash
python scripts/learn.py go
```

安排顺序是：

1. 上次的学习或复习没做完，就接着做。
2. 有到期复习，就只复习排在第一的那一章。
3. 没有到期复习，就学下一章还没达到「已学」的章节。
4. 学过的章节都已及格，而且今天没有到期复习，就建议做一套模拟卷。

科目顺序是综合能力、实务、法规与政策。章节顺序写在 `scripts/learn.py` 的 `CHAPTER_ORDER`，从「社会工作服务的内涵」开始。同一章名如果两科都有卡片，会各自学一遍。某一章测验不到 60 分，状态是「需重修」，下一次会先进复习，不会把它跳过。

还没有任何学习记录时，先说明三科都要 60 分、两年滚动发证，然后只给出今天这一章。

## 可以做的八件事

1. 章节学习。知识点、口诀、易混点、速记要点，然后按科目收尾。
2. 复习。只复习学过的章节。回顾口诀和易混点，重做错题，再小测。
3. 章节测验。单独抽某一章，默认 10 题。
4. 按卷练习。按某一份真题或模拟卷的原顺序做。
5. 模拟考试。按上面的真题结构出整卷，不减少题量。
6. 错题重练。只抽还没攻克的题。连续做对 2 次改为已攻克。
7. 速记。只看某一章的口诀和易混点，不记进度。
8. 学习报告。各章分数、到期复习、各科正确率。

## 章节学习

没指定章节时先看建议：

```bash
python scripts/learn.py status
python scripts/learn.py start --subject 综合能力 --chapter 个案
```

每讲完一节，说「继续」，再进入下一节：

```bash
python scripts/learn.py next
```

前四步三科一样，一次只展开一步：

1. 知识点
2. 记忆口诀
3. 易混点解析
4. 速记要点

口诀和易混点用卡片里的原文讲，不另编一套说法。

后面按科目分叉：

- 综合能力：抽 5 道已经归到这一章的题。题不够 5 道就做完现有的。
- 法规与政策：先做最多 3 道数字填空，再做 5 道章节测验。填空把周岁、日、天、年、级、个月、倍这些数字挖掉，单位留着。脚本对数字。填错就给出正确答案、这一条口诀和原句。
- 实务：不抽选择题。抽一道近年真题案例，只出示题干。写完后由教练打分，不自己对答案。

实务案例分析看四层：问题、理论、目标、介入。方案设计看四层：对象、目标、理论、内容。每层 5 分，共 20 分。某一层写出了实质性内容就算命中，不要求和参考答案原句一致。只有标题、空话，或完全没写，算未命中。教练先对照存放着的参考答案判断，再记分，然后说明每一层为什么给分，并给出参考答案。

章节成绩按百分计：

| 分数 | 等级 | 状态 |
| --- | --- | --- |
| 90 及以上 | 掌握 | 已学 |
| 75–89 | 良好 | 已学 |
| 60–74 | 及格 | 已学 |
| 60 以下 | 需重修 | 需重修 |

实务案例的 20 分会换算成这个百分成绩。写对两层是 10 分，换算 50 分，仍是需重修。写对三层是 15 分，换算 75 分，记为良好。

只说「速记」、不想记进度时，走下面的速记，不进入这五步。

## 复习

没学过的章节不进复习。

```bash
python scripts/review.py status
python scripts/review.py start --subject 综合能力 --chapter 个案
```

到期从上次复习那天算。没有单独的复习日，就用第一次学完的日期。

| 等级 | 间隔 |
| --- | --- |
| 需重修 | 当天 |
| 及格 | 2 天 |
| 良好 | 5 天 |
| 掌握 | 10 天 |

这一章还有未攻克错题时，没到间隔也会进入复习。队列里优先排需重修，其次是错题多的，再是过期更久的。

复习只有三步，不把学习的前四步再走一遍：

1. 回顾这一章的易混点和口诀。
2. 重做这一章未攻克的错题，最多 5 道。没有就跳过。
3. 再抽 5 道题小测，用新分数覆盖这一章的成绩、等级和下次复习时间。第一次学习的日期保持不变。

## 刷题和模拟考

一次一题。客观题由脚本判分，教练按脚本的对错、正确答案和解析来讲，不另猜一个答案。

```bash
python scripts/quiz.py start --mode chapter --subject 综合能力 --chapter 个案 --n 10
python scripts/quiz.py grade --answer C
python scripts/quiz.py grade --answer ABD
python scripts/quiz.py next
```

科目只用 `综合能力`、`实务`、`法规与政策`。章节写关键词即可，能和题库里的章节名对上就抽这一章。对不上「未分章」的题不会抽进来。可以加 `--kind 真题` 或 `--year 2026`。默认中级，要练初级时加 `--level 初级`。

按卷是沿着某一份试卷的原顺序做，不折成 100 分卷面：

```bash
python scripts/quiz.py start --mode paper --paper 2026社会工作者中级真题及答案解析：综合能力
```

`--paper` 写来源路径里能唯一对上这一份卷的一段文字。

模拟考必须指定科目，并且忽略缩短题量的参数：

```bash
python scripts/quiz.py start --mode mock --subject 综合能力
python scripts/quiz.py start --mode mock --subject 法规与政策
python scripts/quiz.py start --mode mock --subject 实务
```

综合和法规先出 60 道单选，再出 20 道多选。实务从真题案例里抽 4 道分析和 1 道方案设计。全部做完打印卷面分，60 分及格，并记入模考记录。

错题重练：

```bash
python scripts/quiz.py start --mode wrong --n 10
```

## 判分和错题

- 单选、判断：1 分，全对才算对。
- 多选：全对 2 分。错选、多选 0 分。少选时每个选对的选项 0.5 分。少选仍然进错题本，也不算进正确率的「做对」。
- 学习流程里的实务案例：教练按四层打分，脚本把结果写成这一章的成绩。
- 测验和模拟考里的案例用三档：全对、半对、错误。模拟考按 20、10、0 分计入卷面；没有卷面分的案例按 1、0.5、0。还没给出档次时，脚本先输出参考解析，等档次确定后再记分。半对和错误进错题本。
- 错题连续做对 2 次改为已攻克，之后不再抽出。
- 中途停下时，已经判过的题留在进度里。

法规数字填空：

```bash
python scripts/numbers.py grade --answer 60 16
```

两个数字之间留空格。顺序要和空格一致。

## 速记

卡片来自考前三页纸、记忆口诀和实务答题模板，放在 `suji/cards.jsonl`。易混点在 `suji/mixups.json`。思维导图是图片，没有收进卡片。

```bash
python scripts/suji.py
python scripts/suji.py --subject 综合能力
python scripts/suji.py --subject 法规与政策 --chapter 社会救助
python scripts/suji.py --subject 综合能力 --mix
```

没指定章节时只列出章节。指定章节后一次只展开这一章，顺序是口诀、易混点、要点。速记本身不写进度。讲完可以再抽 5 道题检验。

章节名单和跨章易混在 `references/exam-map.md`。

## 进度存在哪里

这些文件在使用后才出现，安装包里不带个人记录：

| 文件 | 作用 |
| --- | --- |
| `progress.json` | 教材版本、各章成绩、模考、各科作答 |
| `progress.md` | 给人看的进度 |
| `wrongbook.json` | 错题 |
| `wrongbook.md` | 给人看的错题 |
| `runtime/` | 没做完的学习、复习、测验、填空或案例 |

看报告：

```bash
python scripts/learn.py status
python scripts/quiz.py report
```

换电脑时把这几个文件一起拷走，进度才能接着用。删掉它们就从零开始。

## 环境

需要 Python 3.10 或更高版本。在技能目录里运行命令。技能目录是含有 `SKILL.md` 的那一层：`skills/zhongji-shegong-exam`。

Windows 终端中文乱码时，在命令前加 `-X utf8`：

```bash
python -X utf8 scripts/learn.py today
```

## 安装

把含有 `SKILL.md` 的文件夹放到助手读取技能的位置。文件夹名保持 `zhongji-shegong-exam`，不要再套一层同名目录。

解压 `zhongji-shegong-exam-1.0.0.zip` 后，要复制的是：

`zhongji-shegong-exam/skills/zhongji-shegong-exam`

用户级安装，所有项目都能用：

| 助手 | 放到这里 |
| --- | --- |
| Cursor | `%USERPROFILE%\.cursor\skills\zhongji-shegong-exam` |
| Claude Code | `%USERPROFILE%\.claude\skills\zhongji-shegong-exam` |

只在某一个项目里用时，放到该项目的 `.cursor/skills/` 或 `.claude/skills/`。其他会读取 `SKILL.md` 的助手，放到它自己的 skills 目录，规则相同。

Cursor 也可以从界面导入整个插件目录，或导入同目录下的 zip：Customize → Import from Disk，范围选用户。导入后新开一个对话，输入 `/zhongji-shegong-exam`。界面没有认出插件时，用上面的文件夹复制。

不使用这些软件时，把任意能读 Markdown 的助手指到 `SKILL.md`，工作目录设为技能目录，由它按流程调用 `scripts/`。脚本也可以自己在终端里运行。

装好后从零开始。第一次对话如果进度里教材版本还是「未记录」，先选定中社版或人大版：

```bash
python scripts/quiz.py edition 中社版
```
